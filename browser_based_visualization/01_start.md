
Let's Learn Some Basic Browser Visualization Tricks
===================================================

The web browser is really one of the most amazing technical tools in the modern 
world. Freely available to everyone, ubiquitous, flexible, highly optimized,
and capable of graphics, sound, interactivity, even data analysis if you want.

If you had to, you could make your browser do anything any other software tool
does and, in fact, we've seen that already: things like RStudio and this book
software basically press the browser into the space of general purpose computing.

On top of all that, its operating system independent, and anything built for the 
browser is (almost) immediately shareable.

Today I'm going to give you a whirlwind introduction to using the browser for the 
purposes of communicating data analysis.

We will begin with the basic semantics of ::02_js:Javascript::.
