A Brief Note on Asynchronous Programming
========================================

The browser has a key problem: it wants to enable the developer/user to write
javascript to do things, but it needs to remain interactive, people need to click
stuff, the browser needs to react. 

Rather than open the can of worms that is parallel programming, the browser
has a simpler solution: asynchronous programming.

In this model the browser sits around waiting for various things to happen:
the page is loaded, the document is rendered, an http request finishes
and gives back a result, the user clicks on something. These are called
events. 

The programmer can attack functions to "event listeners" - basically lists
of functions which should be called (sometimes with useful arguments) when
something happens. 

These functions are executed top to bottom when the events occur. While they 
are running *no other js on the page* executes. So the page is really
only ever running one chunk of code at a time from start to finish. 

We can see this like this:

``` js demo

function repeatN(fn, n, delay) {
  let count = 0;
  function run() {
    if (count++ < n) {
      fn(count);
      setTimeout(run, delay);
    }
  }
  run();
}

// Example usage
repeatN(i => console.log("tick", i), 5, 1000);
console.log("After calling repeat.")


```
This idea is *everywhere* in JS - literalyl anything that might wait or take time or load some data 
will have some way for us to register an event listener. We'll see this shortly in our d3 example.

The Big Idea
============

Now we can begin to understand what the deal with d3 is.

Just like ggplot, d3 is based on the idea of combining:

1. data 
2. geometries (in the for of *elements* of an html page)
3. and their attributes or aesthetics

While its not quite as declarative as ggplot, the basic idea is the same EXCEPT
that d3 is built from the bottom up to support *interactivity* and thus
we need to consider the idea of data *entering* and *exiting* the visualization
as well as a few other interactive ideas. 

But before we do that, we need to know how to load and pre-process data:

``` html openable
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>D3 CSV Load</title>
</head>
<body>
  <script type="module">
    import * as d3 from "https://cdn.jsdelivr.net/npm/d3@7/+esm";

    d3.csv("source_data/tidy_wide_characters.csv").then(data => {
      console.log("Loaded rows:", data.length);
      console.log(data);
    }).catch(console.error);
  </script>
</body>
</html>

```
We often need to pre-process our data. D3 loads csvs for us, but won't convert
values to numbers or anything like that.

``` html openable
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>D3 CSV Load</title>
</head>
<body>
  <script type="module">
    import * as d3 from "https://cdn.jsdelivr.net/npm/d3@7/+esm";
    
    const convert_to_number = (d,key) => d[key] = +d[key];
    const numerical_columns = "intelligence,strength,speed,durability,energy projection,fighting skills"
                                 .split(",");

    d3.csv("source_data/tidy_wide_characters.csv",
            row => {
                numerical_columns.forEach(k => convert_to_number(row, k));
                return row;
            })
        .then(data => {
            console.log("Loaded rows:", data.length);
            console.log(data);
        })
        .catch(console.error);
  </script>
</body>
</html>
```
The idea here is that we pass a function to the csv method and this 
is called for every row of the csv file, allowing us to make
appropriate and necessary changes to the data before we do anything else.

Finally we are ready to actually *do something* with the data. Let's just start simple and create a line for each
element in the data set.

``` html openable
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>D3 CSV Load</title>
</head>
<body>
  <script type="module">
    import * as d3 from "https://cdn.jsdelivr.net/npm/d3@7/+esm";
    
    const convert_to_number = (d,key) => d[key] = +d[key];
    const numerical_columns = "intelligence,strength,speed,durability,energy projection,fighting skills"
                                 .split(",");

    d3.csv("source_data/tidy_wide_characters.csv",
            row => {
                numerical_columns.forEach(k => convert_to_number(row, k));
                return row;
            })
        .then(data => {
            d3.select("body")
              .selectAll("p")
              .data(data)
              .join("p")
              .text(row => row["character_name"])
        })
        .catch(console.error);
  </script>
</body>
</html>
```
Hardly a visualization at all, yet, but the key ideas are here.

1. first we decide where in the document we are going to work: `select("body")` means "start working at the body of the page"
2. we then decide what sort of things we want to work *with*: `selectAll("p")` means "all paragraph elements" - this can be confusing at first because our page is empty, so there are none. But it will make sense later. For now think of it as the intent to create "p" elements.
3. then we join our data - in a real sense the idea here *is* a join - we want to connect each bit of our data to a bit of the document (an element of type p)
4. after that we just need to tell d3 how we want to connect our data to aspects of the elements we are creating. Here we are setting the text of the element to the character name. We do this by giving a function that literally maps each row to a value.

Let's do another example to drive the point home.

Let's add some color coded bars to indicate the stats of the characters.

``` html openable
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>D3 CSV Load</title>
</head>
<body>
  <script type="module">
    import * as d3 from "https://cdn.jsdelivr.net/npm/d3@7/+esm";
    
    const repeat = (n,c) => {
        const out = []
        for(let i = 0; i < n; i++){
            out.push(c);
        }
        return out
    }
    
    const bar = (color,n) => `<span style="color: ${color};">`+repeat(n,"█").join("")+"</span>"
    
    const traitsToColors = {
        intelligence: "green",
        strength: "blue",
        speed: "yellow",
        durability: "purple",
        "energy projection": "orange",
        "fighting skills": "red"
    };
    
    const to_html = row => {
        var output = row["character_name"] + ":";
        Object.keys(traitsToColors).forEach(k => {
            output += bar(traitsToColors[k],row[k])
        })
        return output
    }
    
    const convert_to_number = (d,key) => d[key] = +d[key];
    const numerical_columns = "intelligence,strength,speed,durability,energy projection,fighting skills"
                                 .split(",");

    d3.csv("source_data/tidy_wide_characters.csv",
            row => {
                numerical_columns.forEach(k => convert_to_number(row, k));
                return row;
            })
        .then(data => {
            d3.select("body")
              .selectAll("p")
              .data(data)
              .join("p")
              .html(to_html)
        })
        .catch(console.error);
  </script>
</body>
</html>
```
Ok. So the basic idea, again:

1. figure out where
2. figure out what (geom)
3. figure out the data (join)
4. wire up the aesthetics
