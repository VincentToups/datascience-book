We're all losing our minds here by now so let's cover this quickly.

R6 was invented to be a little more principled and a little more performant than R5 but its the same kind of object system: we define classes, values, methods all in one place and we have single dispatch. 

Note that we now gave multiple types of slots and methods: public and private.
This allows the user to encapsulate certain aspects of a class from outside users. The idea here
is that we may wish to change the way a class works internally without worrying about breaking 
external code. If we restrict our changes to purely private variables and methods and
leave the public facing functions and values alone, then we can be sure that our
changes will not outright break other code.
